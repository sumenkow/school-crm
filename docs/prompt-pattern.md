# Паттерн передачи задач и макетов в Antigravity

При передаче визуальных интерфейсов, макетов экранов или доработок используйте следующий шаблон промпта, чтобы результат был точным, без хардкода и с первого раза:

```markdown
Контекст:
Мы работаем над [компонентом / разделом], файл `[Путь_к_файлу]`.
Целевая платформа: [Desktop (от 1280px) | Mobile (смартфоны)] — разрабатываем строго для этой платформы, не ломая другую!
Сверяйся с нашими правилами в `.antigravityrules`, `AGENTS.md` и схемой в `docs/schema.md`.

Задача:
Переверстай компонент строго по прикрепленному макету: [Прикрепить скриншот/макет]

Требования к реализации:
1. Визуальный ряд: один-в-один повтори геометрию, отступы Tailwind, бейджи и кнопки с макета. Сетка под целевую платформу (Desktop или Mobile).
2. Данные: данные брать строго динамически из существующих пропсов / состояния / Supabase (никакого текста с картинки вроде «15 из 16» или чужих номеров телефонов в коде быть не должно!).
3. Интерактив:
   - Все ссылки, бейджи и кнопки должны иметь реальные обработчики событий (onClick, onChange).
   - Кнопки мессенджеров (WhatsApp / Telegram) открывают реальные ссылки на чаты.
   - Телефон форматируется и кликабелен / копируется.
4. Ограничения:
   - Новых таблиц и колонок в Supabase не создаем.
   - Иконки — строго официальные SVG из `lucide-react`.
   - Заполненная группа окрашивается в зеленый (emerald), а не красный.
5. Проверка: Запусти `npm run build` и убедись в отсутствии ошибок TypeScript и JSX.
```
